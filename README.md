# 토리의 미로 탈출

초등학교 5학년이 순서도 기호로 미로 탈출 순서를 직접 그려 보며 **순차 · 반복 · 선택**을 익히는 웹앱입니다.

## 구성

- **0단계 – 순서도 기호 안내**: 시작/끝, 처리, 흐름선, 반복, 판단 기호 설명과 생활 속 예시, 기호 퀴즈
- **1–2단계 순차**: 처리 기호만으로 탈출. 2단계에서 같은 명령을 8번 써 보며 반복의 필요성을 느낌
- **3–5단계 반복**: 반복 기호 사용, 처리 기호 개수 제한으로 반복을 쓰도록 유도
- **6–8단계 선택**: 길이 바뀌는 여러 미로를 하나의 순서도로 탈출하며 판단 기호 사용
- **9–10단계 종합**: ‘출구에 도착할 때까지’ 반복 안에서 여러 판단을 함께 사용

## 기능

- 기호 팔레트를 누르면 순서도 작업판에 기호가 생기고, 칸에 내용을 직접 입력 (회색 예시 글씨 제공)
- 토리가 순서도대로 움직이는 실행 애니메이션
- 틀린 횟수에 따라 생각 힌트 → 구조 힌트 → 거의 정답 → 모범 답안 순으로 도움 제공
- 진행 기록은 브라우저(localStorage)에 저장
- 선생님 모드: 모든 단계 열기

## 사용 방법

설치가 필요 없는 HTML 파일 하나입니다. `index.html`을 브라우저로 열거나 GitHub Pages로 게시하면 됩니다.
